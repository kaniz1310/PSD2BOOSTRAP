#knzPSDB – PSD to HTML Responsive Landing Page

## Overview
knzPSDB is a modern, visually rich PSD-to-HTML conversion project developed using HTML and CSS. The project demonstrates strong UI implementation skills, pixel-perfect design conversion, custom font integration, and clean asset management. It was created as a frontend practice and portfolio project to showcase real-world design-to-code workflow.

This project is ideal for demonstrating frontend fundamentals to recruiters and hiring managers.

## Project Type
PSD to HTML Conversion  
Static Responsive Landing Page

## Technologies Used
- HTML5  
- CSS3  
- Custom Fonts (Poppins Family)  
- Responsive Layout Techniques  

## Key Features
- Pixel-perfect PSD to HTML conversion  
- Clean and structured HTML markup  
- Custom font integration using Poppins font family  
- Well-organized assets and folder structure  
- Modern UI layout with visual balance  
- Cross-browser compatible  

## How to Run the Project
1. Download or clone the repository:
2. Open the project folder  
3. Open `index.html` in any modern web browser  

No external libraries or installations are required.
